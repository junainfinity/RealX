# A50 - Design extension A: investor and sponsor screens not in the prototype

**A second dc-format prototype file, `RealX App Ext A.dc.html`, written in the same language as `RealX App.dc.html` and run by the same `support.js`, that draws the 27 investor, public, governance, account and sponsor screens the prototype does not show or shows only in part (PUB-02, PUB-05 as the standalone sponsor profile page, PUB-07, PUB-08, PUB-09, ONB-04, ONB-07, INV-04, INV-06, INV-07, POR-02, POR-03, POR-06, GOV-01, GOV-02, ACC-01 to ACC-05, SPN-01, SPN-11 to SPN-16), the investor, sponsor and partner passkey sign-in and sign-out screens, the partner variant of the light sidebar, the six new blocks they need (SliderField, OrderBook, ThresholdMeter, TextArea, ScopePicker, MandateSummary), and the drawn-screen supplements of §10 (the product-map components and states that drawn investor and sponsor screens lack), so that every later UI node has a visual reference in the prototype's own tokens and the founder approves it in the browser before any of them starts.**

**Build status:** not started. **Milestone:** AM2 (Token and wallet core; moved from AM4 on 24 Sep 2026 so that this build and the user's HG-REVIEW run on idle streams while the backend is built, instead of on the P1 path; its dependents are all in AM4 or later, and they still wait for the sign-off). **Lane:** Design. **Planner:** Opus 5.5 (high). **Builder:** Grok 4.7 (xhigh). **Node QA:** Opus 5.5 (high, every loop). **Graph QA:** Fable 5.1 (high, at milestone close).
**Estimate:** 14-18 agent-hours (build, challenge and verify loops; raised on 24 Sep 2026 for the added token-screen states, the partner token page and the product-map coverage test).

**Depends on:** [[A05 - Design system package from the prototype tokens]], [[A00 - Charter and acceptance baseline]], [[A03 - State machines, gate codes, approval codes and permission matrix as data]], [[A12 - API tokens, scopes, agent principals and mandates for every user type (G22)]] (`screens.json` generates its delegation values from A03's `delegable.ts` and `familiesFor`, and checks its operation ids against A12's frozen `openapi.json` names, §9; both edges are in the graph since 24 Sep 2026)
**Unlocks:** [[A52 - Web app shells, routing and passkey sign-in (public, investor, sponsor)]], [[A55 - Public site- how it works, returns calculator, transparency, help and documents]], [[A56 - Onboarding flow ONB-01 to ONB-10 with entity branch]], [[A58 - Portfolio, holding detail, transactions, distributions and statements]], [[A59 - AUD wallet, token wallet and account screens]], [[A60 - Investor and sponsor API tokens and agents screens (ACC-05, SPN-16)]], [[A62 - Sponsor console- apply, dashboard, team and approvals, billing]], [[A64 - Sponsor console- register, distributions, property reporting, valuations, announcements]], [[A92 - P2- resale board screens (sell, buy on the board, market tracker, board control)]], [[A93 - P2- governance votes and meetings (SM-10) with screens]], [[A105 - Partner portal- trustee-RE, auditor, regulator observer and licensee views]]

**Oracle rule:** this node has no hidden oracle (`oracle: no`); no money, supply or holdings move here, and the file is a prototype, not product code. The node QA still writes its Challenge material to `<workspace>\gauntlet\hidden\A50\` before the build starts: its own token extractor run over the extension file (independent of the builder's fidelity test), the list of screen codes and states it expects to find, the twelve reference-region crops of the original prototype it will compare against, and the scratch-copy mutations used in the challenges below. The builder never reads that folder ([[App Gauntlet]] §2).

This node draws pictures and click-through behaviour with mock data. It decides nothing about eligibility, money, approvals or authority; every rule the screens show as a pill, a banner or a disabled button is enforced server-side by the API in later nodes (architecture brief §1.1). The extension is a design reference for builders and a review surface for the founder (HG-REVIEW). This plan is not legal advice.
